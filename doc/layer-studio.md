# 图层工作台：Seedream 5.5

本页说明已合入代码的功能。接口理论能力不等于所有场景均已实测。

## 使用方法

1. 从顶部导航进入“图层”，上传源图片，填写希望如何分解主体、文字和背景的提示词。
2. 使用已配置的 BytePlus Seedream 5.5 接口，选择 Auto、1K、1.5K 或 2K 分辨率。实际请求保留配置中的模型 ID。
3. 设置“最大输出数（含底图）”：整数2–100，默认30。它是上限而非保证返回数量；100表示一张底图加最多99个图层。
4. 需要文字信息时勾选“识别文字”（默认关闭），再点击“分解图层”；已有项目点击“创建新版本”。每次操作创建真实后端任务。
5. 选中图层后，在属性区展开“文字识别”，查看或复制全文；展开行详情可查看底图坐标系中的像素坐标、归一化坐标与文字样式。原始OCR JSON也可展开和复制。

OCR只适用于接口能识别的常规文字层。底图、非文字层或未识别的文字可能没有结果；字体和样式是近似识别，不能视为原设计文件属性。识别不会把像素图层变成可编辑的矢量文字。

## 保存、恢复和导出

OCR全文、换行、行顺序、位置、样式片段及其布尔值随生成结果、项目文档和历史修订保存。恢复历史版本时恢复对应的数据；无OCR的旧版本继续可用。新返回的畸形嵌套OCR结构会被校验，历史畸形数据安全降级显示并保留原始JSON。

日常预览使用缩略图，选中图层使用原图，隐藏图层不加载。PNG/JPEG复合图导出按图层顺序加载原图，保留位置、旋转、透明度和可见性；不会用缩略图作为最终导出。ZIP包含图层原文件与 `manifest.json`，清单保留OCR结构。超过16MB的ZIP缓冲使用临时磁盘。

## 参数与兼容

| 配置 | Provider字段 | 规则 |
|---|---|---|
| 最大输出数 | `layer_decomposition_options.max_images` | 2–100，默认30，包含底图 |
| 识别文字 | `layer_decomposition_options.text_recognition` | 布尔值，默认false |
| 分辨率 | `size` | auto、1K、1.5K、2K |
| 每层识别信息 | `data[].text_recognition` | 全文、lines、bounding_box、runs与style |

模型与选项在任务创建时固定；旧任务缺少新选项时不补发，旧模型不接受5.5专属选项。结果未知时不得自动重复生成。接口没有返回金额时，用量不能当作实际费用，也不能记为免费。

## 验证范围与限制

最终验收版本422b9ea：114项后端、4项桌面浏览器及构建通过，另验证旋转、叠放、透明度和隐藏层的导出像素。一次真实测试使用512×512合成源、1K输出、最大2张并开启OCR，约11.55秒成功返回底图和HELLO透明文字层，全文、坐标和样式完整；用量8191 tokens，金额未知。

100层验证使用小尺寸模拟位图，未验证100张2K图片的内存极限。实现限制：最多100层、项目文档16MB、单层OCR1MB、总OCR8MB；复合导出最多1600万像素、单边8192像素。详情见[独立验收报告](reports/2026-11-13-layers55-review.md)和[任务日志](dev/changes/LAYERS55-20261113.md)。
